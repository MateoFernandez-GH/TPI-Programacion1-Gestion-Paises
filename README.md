## Descripción

Aplicación desarrollada en Python para gestionar información de países mediante lectura de archivos CSV, búsquedas, filtros, ordenamientos y generación de estadísticas.

---

## Estructura del Proyecto

```text
.
├── src/
├── data/
├── docs/
├── capturas/
└── README.md
```

### src/

Contendrá el código fuente del sistema.

### data/

Contendrá el archivo CSV de países.

### docs/

Contendrá la documentación académica y técnica.

### capturas/

Capturas utilizadas en el informe final.

---

## Funcionalidades

- Alta de países
- Actualización de datos
- Búsquedas por nombre
- Filtros por continente
- Filtros por población
- Filtros por superficie
- Ordenamientos
- Estadísticas
